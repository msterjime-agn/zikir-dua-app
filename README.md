# Zikir & Dua

Android-приложение для ежедневного чтения зикров и дуа.

- Языки: русский / türkmençe / Türkçe
- Полностью офлайн
- Ежедневный прогресс и счётчики повторений
- Разделы: утро, перед работой, после намаза, личные дуа, вечер, здоровье, трудности, перед сном
- Аят аль-Курси: кнопка показа полного текста/чтения и перевода

## APK

GitHub Actions автоматически собирает debug APK при push в `main`. После успешной сборки APK доступен в артефакте `ZikirDua-APK`.
